# Machine Unlearning - Research

# Important Papers

1. Gert & Poggio, 2000 – Incremental and Decremental Support Vector Machine Learning (NeurIPS)
    - https://papers.nips.cc/paper_files/paper/2000/hash/155fa09596c7e18e50b58eb7e0c6ccb4-Abstract.html

2. Karasuyama & Ichiro, 2009 – Multiple incremental decremental learning of support vector machines (NeurIPS)
    - https://dl.acm.org/doi/10.5555/2984093.2984196
    - https://proceedings.neurips.cc/paper_files/paper/2009/file/fc221309746013ac554571fbd180e1c8-Paper.pdf

3. Cao & Yang, 2015 – Towards Making Systems Forget with Machine Unlearning (IEEE S&P) 
   - First formal definition of unlearning sets the groundwork for everything.
    - https://www.ieee-security.org/TC/SP2015/papers-archived/6949a463.pdf 

4. Ginart et al., 2019 – Making AI Forget You: Data Deletion in Machine Learning (NeurIPS)
    - First scalable algorithm for data deletion in ML pipelines.
    - https://arxiv.org/abs/1907.05012
    - https://papers.nips.cc/paper_files/paper/2019/hash/cb79f8fa58b91d3af6c9c991f63962d3-Abstract.html

5. Ginart et al., 2020 – Certified Data Removal from Machine Learning Models (ICML)
    - First certified removal guarantees for linear models	Introduced rigorous deletion certificates and theoretical foundations
	- https://arxiv.org/abs/1911.03030
	- https://icml.cc/virtual/2020/poster/5895

6. Nguyen,et al., 2020 – Variational bayesian unlearning  (NeurIPS)
   - https://arxiv.org/abs/2010.12883
   - https://dl.acm.org/doi/10.5555/3495724.3497068
   - https://proceedings.neurips.cc/paper/2020/file/b8a6550662b363eb34145965d64d0cfb-Paper.pdf

7. Bourtoule et al., 2020 – Machine Unlearning [SISA Training] (IEEE S&P)
    - Most cited baseline; partition-retrain strategy that’s easy to present.
    - https://arxiv.org/pdf/1912.03817

8. Nasser , 2021 - Coded Machine Unlearning (IEEE)
   - https://ieeexplore.ieee.org/abstract/document/9458237

9. Golatkar et al., 2020 – Eternal Sunshine of the Spotless Net (NeurIPS)
   - Selective class forgetting in CNNs, benchmark reference work.
   - https://arxiv.org/abs/1911.04933
   - https://www.youtube.com/watch?v=OijT2gL7gyA 
   - https://openaccess.thecvf.com/content_CVPR_2020/papers/Golatkar_Eternal_Sunshine_of_the_Spotless_Net_Selective_Forgetting_in_Deep_CVPR_2020_paper.pdf
   - https://openaccess.thecvf.com/content_CVPR_2020/supplemental/Golatkar_Eternal_Sunshine_of_CVPR_2020_supplemental.pdf

10. Golatkar et al., 2020 – Forgetting Outside the Box (ECCV)
   - Forgetting from black-box model access — practical relevance.
   - https://arxiv.org/abs/2003.02960
   - https://www.ecva.net/papers/eccv_2020/papers_ECCV/papers/123740375.pdf

11. Golatkar et al., 2021 – Mixed-Privacy Forgetting in Deep Networks (CVPR)
    - https://arxiv.org/abs/2012.13431

12.  Laura et al., 2021 – Amnesiac Machine Learning (AAAI)
   - Statistical guarantees and multiple retraining-free methods.
   - https://arxiv.org/abs/2010.10981
   - https://cdn.aaai.org/ojs/17371/17371-13-20865-1-2-20210518.pdf

13. Sekhari et al., 2021 – Remember What You Want to Forget (NeurIPS)
    - Efficient removal while retaining accuracy — optimization-based.
    - https://neurips.cc/virtual/2021/poster/26644
    - https://arxiv.org/abs/2103.03279

14. Izzo et al., 2021 – Approximate Data Deletion in Machine Learning (ICLR)
   - Approximate but efficient data deletion framework.
   - https://arxiv.org/abs/2002.10077
   - https://par.nsf.gov/servlets/purl/10224695

15. Neel et al., 2021 – Descent-to-Delete : Gradient-Based Methods for Machine Unlearning (ICML)
   - First gradient-based unlearning method, important for scalability.
   - https://arxiv.org/abs/2007.02923

16. Chundawat et al., 2023 – Zero Shot Machine Unlearning (IEEE TIFS)
    - Highlights efficiency — useful transition paper toward "without data".
    - https://arxiv.org/abs/2201.05629
    - https://www.researchgate.net/publication/369890983_Zero-Shot_Machine_Unlearning
    - https://ieeexplore.ieee.org/document/10097553

17. Chundawat et al., 2023 - Fast Yet Effective Machine Unlearning (ARXIV)
    -  https://arxiv.org/abs/2111.08947

18. Foster et al., 2022 – Fast Machine Unlearning (AISTATS)
    - One of the fastest retraining-efficient approaches.
    - https://arxiv.org/abs/2308.07707
